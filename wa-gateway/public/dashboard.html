Panduan Integrasi dengan Laravel

WA Gateway ini siap dihubungkan langsung dengan backend Laravel Anda melalui HTTP Client atau Guzzle.

1. Kirim Pesan / Broadcast dari Laravel

Gunakan endpoint POST /api/broadcasts:

use Illuminate\Support\Facades\Http;

$response = Http::withToken($jwtToken)->post('http://localhost:3000/api/broadcasts', [
    'device_id' => 1,
    'title' => 'Pengingat Obat Pasien',
    'message' => 'Halo {name}, mohon jangan lupa minum obat sesuai resep dokter.',
    'recipients' => [
        ['phone_number' => '08123456789', 'name' => 'Ahmad'],
        ['phone_number' => '08987654321', 'name' => 'Dewi'],
    ],
    'delay_min_ms' => 1500,
    'delay_max_ms' => 3000,
]);

2. Menangkap Webhook Pesan Masuk (Outreach) di Laravel

Buat route di routes/api.php Laravel untuk menerima payload saat pasien membalas:

Route::post('/wa/webhook', function (\Illuminate\Http\Request $request) {
    $sender = $request->input('from');
    $name = $request->input('sender_name');
    $message = $request->input('message');

    \Log::info("Pesan masuk dari {$sender} ({$name}): {$message}");

    // Logika balasan otomatis / simpan ke chat pasien
    return response()->json(['status' => 'success']);
});
